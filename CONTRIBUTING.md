# Contributing

GlideScroll does not accept pull requests. It is a single-author project, and
keeping it that way keeps the licensing simple and the code base coherent.
Pull requests are closed unread; please don't take it personally.

Bug reports and feature requests are very welcome in Issues. The most useful
bug report has four parts:

1. Which app or game you were in.
2. What you did.
3. What happened, and what you expected instead.
4. Your GlideScroll version (bottom-right of the settings window).

"Scrolling felt weird in <app>" is a perfectly good starting point.
